## 🎯 What Is MIDI AI Studio?

**MIDI AI Studio** is a full-stack AI-powered music composition platform that bridges the gap between music theory and production. Whether you're a professional composer, music producer, educator, or hobbyist, this tool lets you **generate, enhance, and edit professional MIDI compositions** using conversational AI.

### The Problem It Solves
- ❌ Manual MIDI composition takes **40-80 hours** per 4-minute piece
- ❌ Orchestration requires mastery of **12+ instruments**
- ❌ Professional music software costs **$2000+** and has steep learning curves
- ❌ No existing tools provide **intelligent style learning** from reference music

### The Solution
- ✅ Generate complete arrangements in **2-30 seconds**
- ✅ AI handles **orchestration, voice leading, and harmonic complexity**
- ✅ **Freemium model** - no upfront cost
- ✅ **Learn styles** from your reference MIDI files
- ✅ **Edit conversationally** - just describe what you want

<summary><strong>📋 View The Prompt Used</strong></summary>

```
Keep the main melody fully intact and positioned in the high register.
Do not alter or revoice the melody in any way — it remains exactly as written.
Add rich orchestral harmony layers beneath the melody, forming at least
5-part harmony for a full ensemble texture.
Maintain smooth voice leading and overall orchestral balance, ensuring
a deep, lush harmonic texture throughout.
Keep the total structure exactly 33 bars.

Use cinematic or symphonic voicing principles:
- High range (D4–A6): Melody remains clear and dominant
- Upper-mid (G3–G5): Light harmonic or supportive lines
- Middle (C3–C5): Core harmonic foundation
- Lower (C2–C4): Deep reinforcement and roots
- Sub-low (E1–C3): Optional octave grounding

Keep harmony openly spaced in lower registers and closer in upper registers
for natural cinematic warmth. Preserve melody as the clear focal point,
while underlying harmony moves slowly, legato, and dynamically supportive.

The final sound should be lush, emotive, and fully cinematic, maintaining
clarity, warmth, and melodic dominance across all 33 bars.
```

## ⚙️ How It Works

### 3-Step Generation Process

```
Step 1: DESCRIBE                Step 2: GENERATE               Step 3: USE
┌──────────────────┐           ┌──────────────────┐          ┌──────────────────┐
│ Natural Language │──────────▶│  Google Gemini   │─────────▶│ Download MIDI    │
│     Prompt       │           │   AI Analysis    │          │ Edit/Arrange     │
│                  │           │                  │          │ in Your DAW      │
│ "Create 16-bar   │           │ Generates musical│          │                  │
│  jazz piano with │           │ specifications   │          │ Sheet music view │
│  swing rhythm"   │           │ (notes, timing)  │          │ Audio preview    │
└──────────────────┘           └──────────────────┘          └──────────────────┘
```

### Generation Pipeline

```
Frontend (React)
      ↓
Authentication (JWT)
      ↓
Rate Limit Check
      ↓
Subscription Validation
      ↓
Java API (Spring Boot)
      ├─ Save to chat history
      ├─ Decrement daily limit
      └─ Forward to Node bridge
           ↓
Node.js Bridge (Express)
      ├─ Parse input/uploaded MIDI
      ├─ Call Google Gemini AI
      ├─ Generate MIDI from specifications
      └─ Return result
           ↓
Back to Java API
      └─ Store file reference
           ↓
Frontend
      ├─ Display notation preview
      ├─ Play audio
      └─ Offer download
```

## 🚀 Quick Start

### For Users (No Installation)

1. **Visit:** [https://midi-generator-seven.vercel.app/](https://midi-generator-seven.vercel.app/)
2. **Sign Up:** Create free account (no credit card)
3. **Start Generating:** Get 5 free MIDI compositions per day
4. **Explore:** Try different styles and lengths
5. **Upgrade:** If needed, subscribe to Pro/Premium plan

### For Developers (Local Setup)

#### Prerequisites
```bash
✓ Node.js 20+ (npm included)
✓ JDK 21+ (Java Development Kit)
✓ Maven 3.8+ (Java build tool)
✓ PostgreSQL 15+ (local or cloud)
✓ Git
```

#### Get API Key
1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Click "Create API Key"
3. Copy and save securely

#### Installation Steps

```bash
# 1. Clone repository
git clone https://github.com/bharath-mnr/midi-generator.git
cd midi-generator

# 2. Setup Frontend
cd frontend
npm install
npm run dev
# Runs on http://localhost:5173

# 3. Setup Node.js Bridge (new terminal)
cd ../backend-node
npm install
GEMINI_API_KEY=your_api_key npm start
# Runs on http://localhost:5000

# 4. Setup Java Backend (new terminal)
cd ../backend-java
# Edit application.properties with DB credentials
mvn clean spring-boot:run
# Runs on http://localhost:8080

# 5. All services running!
✓ Frontend: http://localhost:5173
✓ Node Bridge: http://localhost:5000
✓ Java API: http://localhost:8080
```

#### Environment Variables

**Frontend (.env)**
```
VITE_API_URL=http://localhost:8080
VITE_NODE_BRIDGE_URL=http://localhost:5000
```

**Node.js Bridge (.env)**
```
GEMINI_API_KEY=your_api_key_here
JAVA_API_URL=http://localhost:8080
PORT=5000
```

**Java API (application.properties)**
```
spring.datasource.url=jdbc:postgresql://localhost:5432/midi_studio
spring.datasource.username=postgres
spring.datasource.password=your_password
spring.jpa.hibernate.ddl-auto=update
```

## 🧪 Technical Highlights

### Performance Optimizations

| Challenge | Solution | Result |
|-----------|----------|--------|
| **Race Conditions** | Pessimistic locking on user records | Zero data inconsistencies ✓ |
| **Rate Limiting** | Distributed token bucket algorithm | Scales to 1000+ users ✓ |
| **Cold Starts** | Instance warm-up on boot | P99 latency <3s ✓ |
| **MIDI Size** | Smart compression & polyphony limits | 50-300KB files ✓ |
| **DB Performance** | HikariCP connection pooling | 10-100x faster queries ✓ |

### Security Implementation

- ✅ **JWT Authentication:** Stateless, scalable user sessions
- ✅ **Rate Limiting:** Per-user quotas prevent abuse
- ✅ **Daily Resets:** Zero-downtime automatic resets
- ✅ **CORS Protection:** Domain-based request validation
- ✅ **Subscription Enforcement:** Hard limits per tier

### Horizontal Scalability

```
BEFORE (Single Instance):
┌─────────────────────┐
│ 1 Java API Instance │ ← 500 concurrent users max
│ 1 Node.js Bridge    │
└─────────────────────┘

AFTER (Load Balanced):
┌─────────────────────────────────────┐
│        Load Balancer (ALB)          │
├─────────────────────────────────────┤
│ Java API #1  Node.js #1             │ ← 1500+ concurrent
│ Java API #2  Node.js #2             │ ← Infinite horizontal
│ Java API #3  Node.js #3             │ ← Scaling
└─────────────────────────────────────┘

All instances share:
✓ PostgreSQL database (HikariCP pooling)
✓ Gemini API quota
✓ JWT secret
```

## 📋 API Documentation

### Authentication

**POST** `/api/auth/login`
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**Response:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "123",
    "email": "user@example.com",
    "subscription_tier": "pro"
  }
}
```

### Generation Endpoints

**POST** `/api/generate/text-to-midi`
```json
{
  "prompt": "Create a 16-bar jazz piano piece in Bb major at 120 BPM",
  "bars": 16,
  "style": "jazz"
}
```

**POST** `/api/generate/enhance`
```
File: original_midi.mid
Body: {
  "prompt": "Add string harmony in cinematic style",
  "style": "orchestral"
}
```

**POST** `/api/generate/style-learn`
```
Files: reference1.mid, reference2.mid, reference3.mid
Body: {
  "num_bars": 32,
  "style_name": "my_style"
}
```
